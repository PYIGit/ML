# 문제 정의서

- 상태: 작성 중 (1절, 2절 확정 2026-11-13. 3 ~ 5절은 4-3 ~ 4-5에서 정한다)
- 이 문서에는 확정된 결정만 적는다. 무엇을 두고 골랐고 왜 그것을 골랐는지는 하위 단계 문서(`4-N_*.md`)의 컨펌 사항에 있다.
- 내용마다 데이터로 확인한 것은 "사실", 이 프로젝트가 정한 것은 "가정"이라고 적었다. 숫자는 train 1,183,747개 부품 기준이다.
- 라인과 스테이션 이름은 익명화된 것이라 실제 Bosch 공정과 같다고 주장하지 않는다.

## 1. 가상 현장

정한 곳: `4-1_VIRTUAL_PLANT.md`

### 1-1. 부품의 흐름

- 공장은 라인 4개(L0 ~ L3), 스테이션 52개다. 흐름도는 `DOCS/03_EDA/figures/3-3_factory_layout.png`다.
- 부품은 L0 또는 L1에서 시작해 L3에서 끝난다. 스테이션 번호 순서가 거치는 순서다(사실).
- `(A|B)`는 같은 작업을 하는 병렬 설비이고 부품은 그중 하나만 거친다. 하나만 거친다는 것은 사실, 같은 작업이라는 것은 가정이다.

| L0 뒤쪽 | `S12-S13-(S14\|S15)-(S16\|S17)-(S18\|S19)-S20-(S21\|S22\|S23)` | `L3_S29` 84%, `L3_S39` 7%, L2 8% |

### 1-3. 검사 지점과 불량 판정

- 검사 지점은 한 곳이다. L3의 마지막 스테이션 뒤에 "최종 검사"가 있고, 부품이 불량인지(`Response`)는 거기서 정해진다(가정). 최종 검사는 데이터에 없는 스테이션이다.
- 불량 부품을 공정 중간에 빼내지 않는다. 부품의 99.9%가 흐름의 끝까지 간다(사실).
- 마지막 스테이션에서 최종 검사까지 걸리는 시간은 정하지 않았다. "남은 시간"은 마지막 스테이션의 시각까지로 센다.

### 1-4. 원인을 정하지 않은 현상

아래 세 가지는 데이터에 있는 사실이다. 원인은 데이터로 알 수 없어서 가정을 두지 않았다.

| 짝: 측정값(numeric 컬럼 968개)이 전부 같은 이웃 부품이 있다 | 부품의 7.6%(90,190개), 불량률 3.65%, 전체 불량의 47.8% | 입력으로 쓸지는 4-3, 분할에서 갈라지지 않게 하는 것은 4-5 |
| `L3_S30` 다음에 `L3_S32`를 거치고 `L3_S33`을 건너뛰는 부품이 있다 | 6,567개, 불량률 15.4%, 전체 불량의 14.7% | 입력으로 쓸지는 4-3 |

## 2. 의사결정 시나리오

정한 곳: `4-2_DECISION_SCENARIO.md`

| 물음 | 정한 것 |
|---|---|
| 언제 | 부품이 L3에 들어가기 전 |
| 무엇을 | 시스템이 위험 점수가 기준값을 넘는 부품을 "확인이 필요한 부품"으로 표시하고 근거를 보여 준다 |
| 누가 | 품질 담당자가 표시된 부품과 근거를 보고 무엇을 할지 정한다 |

### 2-1. 예측 시점

- 예측 시점은 "L3에 들어가기 전" 하나다. 부품이 L3의 첫 스테이션(`L3_S29` 또는 `L3_S39`)에 들어가기 직전이다.
- "모든 스테이션을 거친 뒤"의 예측은 운영 시나리오에 넣지 않는다. 단계 6에서 비교 기준이 필요해지면 그때 만든다.

| 부품 | 예측할 때 쓸 수 있는 측정값 (사실) | 판정까지 남은 시간 (가정: 0.01이 6분) |
|---|---|---|
| L2를 거치는 부품 (30%) | 62개 (전체 207개의 30%) | 약 2일 |
| L2를 거치지 않는 부품 (70%) | 43개 (전체 190개의 23%) | 약 21시간 |

### 2-2. 시스템이 하는 것과 사람이 하는 것

- 시스템이 보여 주는 것: 부품의 위험 점수, 그 점수에 영향을 준 변수, 그 변수가 속한 라인과 스테이션.
- 시스템이 하지 않는 것: 구체적인 조치의 권고, 부품을 흐름에서 빼내는 것, 설비나 공정의 조정. 컬럼이 어떤 설비의 무슨 값인지 모르기 때문이다.
- 무엇을 할지는 품질 담당자가 정한다. "품질 담당자"라는 역할은 가정이다.

### 2-3. 조치 대상을 고르는 방식

- 위험 점수가 기준값을 넘는 부품을 모두 "확인이 필요한 부품"으로 표시한다. 표시되는 부품의 수는 날마다 달라진다.
- 기준값을 얼마로 둘지는 4절(평가 지표)에서 정한다.
