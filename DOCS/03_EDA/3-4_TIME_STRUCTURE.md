# 3-4 시간(date) 구조(Q5)

- 상태: 설계 중 (2026-11-10). 컨펌 사항 5건 미응답. 구현 전
- 관련: `EDA_PLAN.md` Q5, 3.6절, 4절(`station_timing.parquet`), 5절(3-4), 6절 / 선행: `3-3_MISSINGNESS_AND_ROUTES.md`(방문 행렬), `EDA_FINDINGS.md` Q2·Q4의 미확인 항목
- 입력: `DATA/raw/bosch_parquet/`의 `train_date.parquet`, `test_date.parquet`, 3-2·3-3 산출물(`DATA/interim/eda/`)

## 1. 목표

date 컬럼의 값이 무엇인지 데이터로 추정하고(범위, 단위, 스테이션 안에서의 일관성), 부품마다 시각을 정리해 시간에 따른 생산량과 불량률, 불량의 시간적 군집, 스테이션 간 흐름, 처리량·도착 간격·이동 시간을 확인한다. 3-3에서 이월된 질문인 "방문 스테이션 수 12인 그룹의 불량률 6.09%가 특정 시기와 관련 있는가"에 답한다. 단계 4의 분할 전략(시간 기반 분할 가능 여부)과 `Id`가 시간 순서를 담고 있는지(Q8 근거), 단계 7 시뮬레이터의 생성 규칙의 근거가 된다.

## 2. 확인하려는 것

1. **date 값의 범위와 단위 추정**: 최솟값, 최댓값, 소수 자릿수, 고유값 수, 음수 여부. 단위는 데이터로만 추정하고 실제 단위를 단정하지 않는다.
2. **스테이션 안의 D 컬럼 일관성**: 같은 스테이션의 D 컬럼이 한 부품 안에서 같은 값인가. 같다면 스테이션당 시각 1개로 줄일 수 있다. 다른 스테이션은 어디이고 차이는 얼마인가.
3. **부품별 최초 시각, 최종 시각, 소요 시간**(최종 - 최초)의 분포
4. **스테이션 간 시각 순서로 추정한 흐름**: 스테이션 쌍마다 "한 부품에서 A의 시각이 B보다 앞서는 비율", 스테이션별 평균 시각 순서와 스테이션 번호 순서의 비교. 관찰된 순서이며 실제 공정 배치로 단정하지 않는다.
5. **시간 구간별 생산량과 불량률 추이**: 구간별 부품 수, 불량 수, 불량률, Wilson 구간, 소표본 표시
6. **train과 test의 시간 범위 비교**: 두 파일의 시각 범위와 구간별 부품 수. 시간 기반 분할이 가능한지의 근거다.
7. **스테이션별 처리량, 도착 간격, 이동 시간**: 구간당 통과 부품 수, 같은 스테이션에 연속으로 도착하는 부품 사이의 간격 분포, 항목 4에서 추정한 순서에서 이웃한 스테이션 사이의 이동 시간 분포
8. **불량의 시간적 군집성**: 불량이 시간축에 고르게 퍼져 있는지, 특정 구간에 몰려 있는지. 몰려 있다면 구간의 길이와 위치
9. **`Id` 순서와 시각 순서의 관계**: `Id`가 시각에 따라 단조 증가하는가, 섞여 있는가
10. **방문 스테이션 수 12인 그룹의 시간 분포**(3-3에서 이월): 이 그룹 부품의 시각 분포, 그룹 안의 시간 구간별 불량률, 이 그룹의 불량이 몰린 시기가 항목 8의 군집 구간과 겹치는지
11. **계산 검증**: 스테이션별 시각 요약이 독립 계산과 같은지, 구간 표의 합계가 맞는지, 군집성 검정이 합성 데이터에서 의도한 대로 동작하는지

설계 근거로 층화 샘플 `sample_date_stratified.parquet`의 앞 50,000행을 미리 살펴본 값(결과 아님, 불량이 많이 들어간 샘플이라 분포가 전체와 다를 수 있음):
- date 값은 0.01 ~ 1718.48(샘플 전체)이고 소수 둘째 자리까지 있다.
- 같은 스테이션의 D 컬럼은 대부분 한 부품 안에서 값이 같았다(컬럼이 2개 이상인 49개 스테이션 중 47개가 전 부품에서 같음). 다른 스테이션은 `L1_S24`(컬럼 288개, 값이 있는 7,642개 부품 중 20개만 같음), `L1_S25`(컬럼 333개, 3,468개 중 9개만 같음)였다.
- `Id`와 부품 최초 시각의 상관은 0.005이고, `Id` 순서로 늘어놓았을 때 시각이 줄지 않는 비율이 50.5%였다. `Id`가 시각 순서를 따르지 않는 것으로 보인다. 전체 행에서 확인한다.

항목별 방법:
- **값 범위(항목 1)**: 스테이션 단위 스트리밍으로 date 컬럼 전체의 최솟값·최댓값, 음수 개수, 소수 자릿수를 센다. 고유값 수는 스테이션별 요약 열에서 센다. 단위는 값의 범위와 이웃 간격(가장 작은 차이)으로만 추정한다.
- **스테이션 일관성(항목 2)**: 스테이션의 D 컬럼 중 값이 있는 컬럼들의 최솟값과 최댓값이 같은 부품 수를 센다. 같지 않은 스테이션은 최대 차이와 분포를 따로 적는다. 컨펌 사항 #1에서 최소·최대를 모두 저장하므로 이 계산이 곧 `station_time_train.parquet`의 열이다.
- **부품별 시각(항목 3)**: 부품의 최초 시각은 모든 스테이션의 최소 시각 중 최솟값, 최종 시각은 최대 시각 중 최댓값이다(컨펌 사항 #2). 소요 시간 = 최종 - 최초. 시각이 하나도 없는 부품(3-3에서 582개)은 제외하고 개수를 기록한다.
- **흐름 추정(항목 4)**: 두 스테이션에 모두 시각이 있는 부품에서 A의 대표 시각(스테이션 최소)이 B보다 앞서는 비율을 계산한다. 52개 스테이션의 쌍 1,326개 모두. 스테이션별로는 시각의 중앙값 순위를 구해 번호 순서와 비교한다. 같은 시각인 비율도 기록한다. 순서가 일관된 쌍(예: 앞섬 비율 95% 이상)이 얼마나 되는지를 센다.
- **구간별 추이(항목 5)**: 최초 시각을 고정 폭 구간으로 나눠(컨펌 사항 #3) 구간별 부품 수와 불량 수를 센다. 불량률에는 3-2의 `rate_table`(Wilson 구간, 소표본 1,000 미만 표시)을 쓴다. 구간 수가 많아 우연히 큰 차이가 나는 구간이 포함될 수 있으므로 눈에 띄는 구간은 가설로만 기록한다.
- **train과 test 범위(항목 6)**: `test_date.parquet`에서 같은 방식으로 최초 시각을 구해 train과 같은 구간으로 부품 수를 센다. test에는 `Response`가 없으므로 불량률은 계산하지 않는다. 겹치는 범위, 각자만 있는 범위를 기록한다.
- **처리량, 도착 간격, 이동 시간(항목 7)**: 스테이션별로 시각순으로 정렬해 이웃한 부품의 시각 차이를 도착 간격으로 본다(같은 시각이면 간격 0). 이동 시간은 항목 4에서 추정한 순서에서 이웃한 스테이션 쌍마다, 두 스테이션에 모두 시각이 있는 부품의 (뒤 스테이션 시각 - 앞 스테이션 시각) 분위수를 기록한다. 시각의 단위를 모르므로 분포는 date 값의 단위 그대로 쓰고 초나 분으로 바꾸지 않는다.
- **군집성(항목 8)**: 구간별 불량 수가 "불량이 시간과 무관하게 무작위로 나열될 때"의 변동 범위 안인지 순열 검정으로 판단한다(컨펌 사항 #4). 부품을 최초 시각순으로 놓고 불량 라벨(6,879개)을 부품 사이에서 무작위로 섞는 것을 5,000회 반복해, 구간별 불량 수가 기대값에서 벗어난 정도(표준화한 제곱합)와 최대 구간 불량률을 관측값과 비교한다. p값은 관측값 이상이 나온 시행의 비율이며 5,000회이므로 해상도는 약 0.0002다. 구간 폭 1, 10, 50으로 각각 계산해 결론이 폭에 따라 달라지는지 본다. 몰려 있으면 불량률이 기대 범위 밖인 구간의 위치와 길이를 기록한다. 원인으로 서술하지 않는다.
- **`Id`와 시각(항목 9)**: `Id`와 최초 시각의 스피어먼 순위 상관, `Id` 순서로 이웃한 부품의 시각이 줄지 않는 비율을 구한다. 그림은 무작위 샘플 10,000개 점이다.
- **12 그룹(항목 10)**: 3-3과 같은 정의(numeric 기준 방문 스테이션 수 12)로 그룹을 만들고(부품 7,221개, 불량 440개가 나와야 한다), 그룹의 최초 시각 분포와 구간별 불량률을 전체와 비교한다. 그룹 부품이 특정 구간에 몰려 있는지, 불량이 몰린 구간이 항목 8의 군집 구간과 겹치는지를 센다. 그룹의 불량은 440개뿐이라 구간별 표는 소표본이 많을 것이며 Wilson 구간으로 표시한다.
- 메모리: 스테이션 단위로 컬럼 100개 이하씩 읽고, 스테이션별 최소·최대를 Float32로 저장한다(값이 소수 둘째 자리라 Float32 오차는 0.001 미만). 피크 메모리 목표는 3 GiB 이하이며 실제 값은 측정해서 기록한다.

**검증**
- 스테이션별 시각 요약(최소, 최대)을 pyarrow로 컬럼을 다시 읽어 전체 행에서 독립 계산한 값과 비교한다(Float32 허용 오차 0.001).
- 구간 표의 부품 수 합이 시각이 있는 부품 수(1,183,747 - 582)와 같고, 불량 수 합이 6,879 - (시각이 없는 불량 2개)와 같은지 확인한다.
- 12 그룹이 3-3의 값(부품 7,221개, 불량 440개)과 같은지 확인한다.
- 군집성 검정은 합성 데이터(무작위 라벨은 p값이 크고, 한 구간에 불량을 몰아 넣은 라벨은 p값이 작음)로 의도한 대로 동작하는지 단위 테스트로 확인한다.
- 층화 샘플의 최초 시각을 numpy로 독립 계산해 `row_time_features.parquet`의 같은 `Id`와 비교한다.

**보고.** 표(값 요약, 스테이션 일관성, 소요 시간 분포, 구간 표, 스테이션 순서, 처리량·도착 간격·이동 시간 요약, 군집성 검정, `Id`-시각 관계, 12 그룹)와 그림 7개, 검증 결과, 피크 메모리. 그림은 `dataviz` 스킬의 규칙을 따라 만든다.
